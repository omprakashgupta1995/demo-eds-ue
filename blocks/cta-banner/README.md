# CTA Banner

Full-width, centred call-to-action section with a bold heading and a single primary button.

## Usage

```
| cta-banner |
| --- |
| Join today. It only takes a few minutes. |
| Become a member → | /en/join |
```

## Fields

| Field | Type | Description |
|---|---|---|
| `heading` | richtext | Bold H2 tagline |
| `col1_ctaText` | text | Button label (e.g. "Become a member →") |
| `col2_ctaUrl` | text | URL the button navigates to |

## Authoring Notes

- `col1_ctaText` and `col2_ctaUrl` share the same xwalk row — they render side by side in the table.
- No child items — this block is flat (no "+ Add" rows needed).
- The `→` arrow character is part of the authored button text, not generated by CSS.
